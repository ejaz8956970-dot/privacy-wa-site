Support & Quick Guide

Need help setting up Privacy WA v1.2.3 Pro on Microsoft Edge or Chrome? Follow the quick answers below.

Keyboard Shortcuts

Alt + X: Toggle Panic Shield ON/OFF (blurs the screen and disables hover-to-reveal).
Alt + L: Lock the extension immediately with your PIN.

Forgot Your PIN?

When you set a PIN, Privacy WA generates a one-time Recovery Code (PWA-XXXXXX). Enter that recovery code in the unlock screen to reset your PIN without losing your saved quick replies or order tags.

Backup & Restore

Use the Export / Import JSON buttons in the extension popup to move your quick replies and order statuses between computers. An import preview always confirms item counts before overwriting existing data.
